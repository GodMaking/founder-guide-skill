# 创业方向判断框架

本文件是 founder-guide 的主流程，用于回答"这件事值不值得做、我现在卡在哪、下一步该干什么"。
判断不靠感觉，靠四步：先问清事实 → 定阶段 → 过三闸门 → 出决策卡。

## 一、先问清五个事实（缺一个就不能往下判断）

顺序固定，一问一答，不许用"大概""应该"糊过去。

1. **替代方案**：用户现在怎么解决这个问题？他为此每年花多少钱、多少时间、忍多少麻烦？
   - 没有替代方案，通常不是机会，是需求不存在
   - 替代方案很烂但仍有人付费，是最肥的缝
2. **付费证据**：有没有人已经为相邻的东西付过钱？
   - 证据分级：已预付/已下单 ＞ 签了意向或框架 ＞ 反复主动询价 ＞ 只在问卷里说"会买"
   - 只有第 4 级，就是还没验证
3. **口袋深度**：账上现金多少、每月净流出多少，还能撑几个月。
   - 这是 runway，不是"大概还能撑一年"
4. **手上有什么**：想法 / 跑通的原型 / 样品 / 已交付的首批客户 / 稳定量产，只能选一个最靠后的
5. **最大可承受损失**：这笔钱和这半年，如果全亏，你的生活会不会崩

五个事实里，第 1、2 条决定方向，第 3、5 条决定你敢走多远，第 4 条决定你现在该干什么。

事实没问清就开始给方案，是这类咨询最常见的失败。

## 二、定阶段：六个台阶

阶段错配是创业里最贵的错误：用规模化阶段的方法解决验证阶段的问题，会烧掉全部现金；用验证阶段的心态做量产，会死在供应链。

| 阶段 | 你在哪 | 过关证据 | 这个阶段最常怎么死 |
|---|---|---|---|
| S0 想法 | 只有一个念头 | 无付费证据 | 直接做产品，做完发现没人要 |
| S1 验证 | 在找人确认需求 | ≥3 个真实付费或预付，来自非熟人 | 拿问卷当验证，自我说服 |
| S2 原型 | 做能跑通的东西 | 核心功能跑通，能演示，能被外行看懂 | 追求完整产品，原型做成工艺品 |
| S3 首批交付 | 有人在用/在买 | ≥10 单重复交付，退款率可接受 | 靠个别大客户撑住，误判为需求广 |
| S4 量产 | 要稳定交付 | 单位成本稳定，瓶颈已识别，良率可控 | 拿原型的成本估算量产，现金断在爬坡 |
| S5 规模化 | 要量换成本 | 单位成本随量下降，护城河成立 | 边扩边亏，规模不带来议价权 |

判断阶段的三个提问：
- 有没有人付过钱？（否 → S0/S1）
- 付钱的人有没有重复？（否 → S3 之前）
- 交付是不是靠手工/靠你本人？（是 → 还在 S3）

## 三、三闸门：可算的判据

每道闸门都要给出数字或明确的"待验证"，不许给"感觉还行"。

### 闸门一 · 有用性

要回答两件事：解决了谁的具体麻烦；你的方案相对替代方案的价值倍数。

- 判据一：目标用户能说出"我现在是怎么忍这件事的"，并且能报出成本（钱或时间）
- 判据二：价值/成本 ≥ 2。也就是同等问题下，你的方案要么便宜一半以上，要么效果好一倍以上。只便宜 10%，用户不会换
- 判据三：不靠补贴也成立。补贴期成立、补贴撤了就崩，说明你的价值不够

埃隆之书的原话可以当尺子：一家公司存在的意义，是持续产出比别人更有用的东西。有用性排在规模之前。

### 闸门二 · 成本与单位经济

三步，必须算到手。

1. **拆到底价**：把产品拆成原材料/外部服务，按市场价算一遍。这是你的理论下限
2. **白痴指数**：当前成品成本 ÷ 原材料成本。倍数越高，说明无效成本越多。实用参考：>5 有大幅压缩空间；>10 说明设计或工艺里有明显冗余
3. **单位经济**：单价 − 单位变动成本 = 单位毛利；固定成本 ÷ 单位毛利 = 盈亏平衡量
   - 盈亏平衡量超过你能触达的客户数，这个模式就不成立

目标差距的判读：
- 差距 ≤ 2 倍：优化能解决，走工程学五步法
- 差距 2–10 倍：要换设计或换工艺，靠删部件而不是改参数
- 差距 > 10 倍：现有方案不成立，必须换技术路线或换商业模式

`scripts/startup_calc.py` 可以直接算这三步，别手推。

### 闸门三 · 时间

- 见效周期（拿到第一笔非熟人付款要多久）与 runway 的关系：超过 runway 的 60%，判定为不可行，除非先做能立刻收钱的小版本
- 一项决定的时间账：这件事占多少时间、晚一个月代价是什么。钱能再融，时间不能
- 能并行的环节先并行：所有"孕育期"（审批、打样、认证、招人）先同时启动

### 闸门四 · 风险红线（一票否决）

以下任一条成立，直接停，不做折中方案：
- 需要资质而你拿不到，或业务本身在监管禁止清单内
- 单点依赖：一个客户超过收入 40%、一个供应商卡住全部产能
- 最大可承受损失被突破（要借钱、要抵押住房、要动家人的钱）
- 现金流为负且没有确定的下一笔钱，却已经开始扩产

## 四、出决策卡

结论只有三种：做（进入下一阶段）、小步验证（7 天内花小钱验证一个假设）、停（不做，或换方向）。
不许出现"值得关注""可以尝试"这种中间态。

决策卡固定字段：

```
一句话业务定义：
目标用户与替代方案：
阶段判定：S?　依据：
闸门一 有用性：过/不过/待验证　数字：
闸门二 单位经济：白痴指数　单位毛利　盈亏平衡量　结论：
闸门三 时间：见效周期　runway　结论：
闸门四 风险：红线项有无
结论：做 / 小步验证 / 停
最小验证动作：谁、在几天内、花多少钱、看哪个指标算过
止损线：钱到多少停　时间到多久停　指标低于多少停
下一步调用：哪本书的哪一条方法，落成哪个具体动作
```

## 五、判断时的五个常见误判

1. **拿熟人验证**：亲友的支持不是市场信号。有效的付费证据必须来自非熟人
2. **拿能力代替需求**：因为你擅长 A，就证明市场需要 A。能力只决定你能做多好，不决定有没有人要
3. **把原型成本当量产成本**：手工打样的成本结构，量产后一定变形。批量越大，越要先算
4. **把增长当护城河**：用户增长快不等于别人进不来。护城河看的是转化成本、规模经济、网络效应、专有技术
5. **用乐观抵时间**：激进时间表可以用来压团队和供应商，但不能用来做现金规划。现金规划按"你估的两倍"

## 六、判断之后

结论为"做"或"小步验证"时，进入 `references/execution-playbook.md`：按阶段取动作，不按顺序跳。
需要具体方法时，从 `references/book-map.md` 按触发条件取件，不要整本读。

每次判断结束，必须写清三件事：这一步的过关证据是什么、花多少钱、什么条件下停。写不出来的判断不算判断。

## 七、复盘：让判断可校准

没有复盘的判断会一直重复同一类错误。每次下结论时留一行账，每季度对一次。

记账格式（一行）：

```
日期 | 结论(做/验证/停) | 当时的判断依据(哪个数字说了算) | 预测(多久、多少) | 结果 | 偏差原因
```

对账规则：

- 结论是"做"但三个月内没达到预期 → 查当时最依赖的那个数字是"已确认"还是"假设"。多数错在拿了假设当证据
- 结论是"停"但事后证明能做 → 查当时的闸门是否用了错的基准（例如用原型成本判量产）
- 连续三次同一类偏差 → 这条判据本身要改，不是执行要改

每季度重跑一次"五个事实"，尤其第 1、2 条。替代方案的成本会变，付费证据也会过期；半年前的判断依据，今天可能已经不成立。

## 八、什么时候说明"书库没有这条"

47 本覆盖的是创业判断、执行、组织、财务、心态，不覆盖具体行业技术、专业资质、法律结论。遇到这类问题，直接说"这条书库里没有"，然后只做两件事：指出要核实什么、建议找谁核实。硬套一本不相关的书，比不回答更糟。
