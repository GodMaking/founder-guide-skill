# 成书结构范式（SAMPLE-FORMAT）

本文件说明一本蒸馏成书的产出结构，**不含任何原书正文或成书全文**。样本只用于对齐格式，不提供可直接复制的内容。

## 目录骨架

```text
NN-书名/
├── book.pdf                  # 原书留档
├── full_text.txt             # 源书全文（解析产物）
├── requirement-checklist.json
├── outline.md
├── chapter-ledger.md
├── manuscript/
│   ├── ch01-xxx.md
│   ├── ch02-xxx.md
│   └── ...
└── deliverables/
    └── final.md              # 合并后的成书正文
```

## 成书正文结构

```markdown
# 书名（蒸馏成书）

## 第一章 章节标题

一、小节标题
（一）更细一层

正文段落……

## 第二章 章节标题
……

## 后记或结语（可选）
```

要点：

- 一级标题只用于书名；章标题统一为 `## 第X章 ...`（汉字数字，从"第一章"连续编）
- 二级标题用"一、"，三级用"（一）"，不跳级
- 每章 1,500–2,500 字为主，全书合计贴合目标字数 ±10%
- 章节之间承担不同论点，不重复叙述同一件事

## 每章的内部写法

| 层次 | 写什么 |
|---|---|
| 开篇 | 用一段话交代本章要解决的具体问题，不写"本章将介绍……"式套话 |
| 主体 | 方法、步骤、判断条件、案例，按原书逻辑组织，不按条目硬拆 |
| 案例 | 保留原书案例的关键事实与结论，不复述无关细节 |
| 收束 | 落到可执行的做法或判断标准，不写空洞总结 |

## 规划表格式（outline.md）

| 章节 | 标题 | 核心问题 | 读者收获 | 目标字数 |
|---|---|---|---|---|
| 第一章 | 示例标题 | 本章回答什么 | 读者能带走什么 | 2,000 |

章节目标字数合计必须等于全书目标字数。

## 校验

```bash
python scripts/distill_check.py <工作目录>
```

全部项通过才交付：字数区间、章节数与编号、占位符、中文占比、空章节、层级、台账回填。
