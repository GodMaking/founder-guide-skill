# founder-guide：创业者指南

创业者指南 = 46 本经典书的方法论精华 + 一套持续蒸馏新书入库存的流水线。已蒸馏的 46 本覆盖创业者从 0 到 1 到做大做强的全维度：创业打法、财商思维、经济规律、投资逻辑、营销成交、团队与职场、个人成长、心态疗愈。每一本都蒸馏成约 3 万字、忠实于原书、可直接阅读与售卖的中文成书。

## 问题契约

```markdown
反复出现的问题：创业者/经营者想把一本或一单经典书快速变成方法论成书，用于学习、内部培训或内容售卖
使用情境：批量书单逐本蒸馏、单本深读浓缩、把书做成可售卖内容资产
用户想推进的变化：从"读完一整本"变成"拿到浓缩的方法论成书，保留原书核心方法与表达"
Skill 应交付的结果：NN-书名/ 工作目录（四件套 + manuscript + deliverables/final.md）+ 原书 PDF；按需上传云盘交付链接
完成证据：final.md 非空白字数落在目标 ±10%；章节数 ≥ 8 且编号连续；无占位符；中文占比 ≥ 70%；四件套齐全
不处理的近邻问题：从零创作原创书（走 ai-novel-production）；Word 排版/党政公文（走 word）；在线长文档创作（走 doubao-book-writer / lark-doc）
```

## 执行流程

1. **解析源书为全文**
   - PDF：先 `pdfinfo` 确认文本层，`pdftotext` 导出全文；扫描版才考虑 OCR
   - 飞书/豆包文档或书单：`lark-cli docs +fetch --doc <URL> --doc-format markdown`，书单条目内 PDF 素材 token 用 `docs +media-preview` 下载（`+media-download` 403 为死路，勿用）
   - 网页/纯文本：读取全文并落盘
   - 全文落盘为 `full_text.txt`，供后续章节取材
2. **初始化工作目录**：运行 `scripts/make_workspace.py "<书名>" --output <父目录> [--target-words 31040] [--chapters 16]`，从 `assets/templates/` 生成四件套初稿
3. **规划四件套**（先规划后成稿，章节目标字数必须完整分配全书目标）
   - `requirement-checklist.json`：主题、源书、需求 R1–R5、wordCountRules（target ±10%）
   - `outline.md`：核心主张 / 目标读者 / 语气 / 章节规划表（章节、标题、核心问题、用户收获、目标字数）/ 章节依赖关系 / 总字数目标
   - `chapter-ledger.md`：章节台账（章节、标题、目标字数、当前字数），成稿后回填当前字数
4. **逐章成稿**：每章一个 `manuscript/chNN-标题.md`，章标题必须"第X章"（汉字数字）；层级"一、"→"（一）"；忠实转述原书，保留关键原句/角色名/专有名词，不虚构不发挥；去 AI 味（少连接词、少模板句、少排比堆砌）
5. **合并 final.md**：按章节顺序合并为 `deliverables/final.md`，顶部保留 `# 书名（蒸馏成书）` 标题与章节结构
6. **校验**：运行 `scripts/distill_check.py <工作目录>`，全部通过才交付
7. **交付**：本地 `final.md` + 原书 `book.pdf`；用户要求云盘时上传 Drive 根目录并交付链接；最终回复 ≤300 字/≤8 行。**商业售卖交付时**先用 `scripts/issue_license.py` 为该买家生成唯一授权编号，并把版权页追加到 `final.md` 末尾

## 校验门槛（完成证据，全部必须通过）

- `final.md` 非空白字数 ∈ [target × (1−10%), target × (1+10%)]
- 章节数 ≥ 8，编号从 ch01 连续；章标题格式 `# 第X章`（汉字数字）
- 无占位符：TODO / 待补 / 占位 / xxx / Lorem / 待插入
- 中文占比 ≥ 70%（非空白字符中 CJK 比例）
- 无空章节：每章非空白字符 ≥ 500
- 层级规范：二级标题"一、"，三级"（一）"，不跳级；标题内不加粗
- 章节规划目标字数合计 = 全书目标字数；台账当前字数已回填

## 停止条件

- 源书无法获取全文（链接失效/权限不足/扫描质量无法 OCR）：停止并说明缺什么
- 用户明确只要大纲或只读问答，不做成书
- 校验连续失败且是源书内容缺失导致（如原书过短、结构无法拆章）：如实报告而非硬凑字数

## 资产与脚本

- `assets/templates/`：四件套模板（requirement-checklist.json、outline.md、chapter-ledger.md）
- `assets/samples/`：`books_index.json`（46 本已入库书目索引）+ `SAMPLE-FORMAT.md`（成书结构范式，仅格式不含原书正文；本仓库不收录任何成书全文）
- `scripts/make_workspace.py`：初始化工作目录四件套
- `scripts/distill_check.py`：独立校验（不依赖外部工具，Python 3 标准库）
- `scripts/issue_license.py`：一客一码授权（生成唯一编号、授权书、成书版权页与本地台账；可选零宽水印嵌入与解码）。台账与授权书含买家信息，只存本地，禁止入库
- `references/distill-workflow.md`：逐章写作细则与去 AI 味规范

## 边界

- 只处理"已有真实源书内容"的蒸馏；没有源书材料时不得编造成书
- 原书有版权：成书是浓缩转述产物，交付时保留原书 PDF 与否按用户要求
- 不擅自把成书导入飞书云文档（历史 46 本用户明确 SKIP_LARK=1，仅交付 md + PDF）；用户主动要求才走云文档
- 许可：非商业使用免费，商业使用（含出售本 Skill 或其产出）需作者书面授权，见仓库根 `LICENSE` 与 `COMMERCIAL-LICENSE.md`
