# founder-guide（创业者指南）

> **一句话定义**：founder-guide 是一个 Agent Skill，把一本书或一份书单，按固定标准蒸馏成约 3 万字、可直接阅读的中文方法论成书。
>
> 输入：PDF / 飞书文档链接 / 网页 / 纯文本 / 书名。输出：`final.md`（成书正文）+ `book.pdf`（原书留档）+ `outline.md` + `chapter-ledger.md`。已在 46 本经典商业与成长书上跑通并固化为标准。

## 这是什么

一个把"读书"变成"产出"的流水线：源书全文解析 → 四件套规划 → 逐章成稿 → 合并校验 → 交付成书。

它不做摘要，也不做读书笔记。它按章节结构重写成一本独立的书：保留原书的核心论点、方法与案例，用中文重新组织表达，篇幅约 3 万字，可以直读、可以做内部培训、可以作为内容资产。

完整书目（46 本）见 `skills/founder-guide/assets/samples/books_index.json`。

## 解决什么问题

创业者的时间被切碎，但方法论必须进脑子。三个真实痛点：

| 痛点 | 具体表现 | 本 Skill 的做法 |
|---|---|---|
| 书太厚 | 一本 300 页的书，真正有用的方法论可能只有 20 页，但你要读完 300 页才能找到 | 直接给出方法论结构，跳过论证冗余 |
| 读完就忘 | 回忆起来只剩"感觉不错"，说不出具体方法 | 输出成书，方法可检索、可复用 |
| 二次加工成本高 | 想讲给团队、写成课程，还要重新翻书整理 | 一次产出可直读、可改写的成书 |

## 和"AI 总结""读书笔记"有什么区别

| 维度 | 普通 AI 总结 | 读书笔记 | founder-guide 成书 |
|---|---|---|---|
| 篇幅 | 几百到几千字 | 随手记，结构散 | 约 3 万字，16 章左右 |
| 结构 | 要点罗列 | 无固定结构 | 章节化，有核心主张与论证线 |
| 忠实度 | 容易发挥、编造 | 依赖个人理解 | 忠实转述，保留原书关键原句与案例 |
| 可交付性 | 只能自己看 | 只能自己看 | 可直接阅读、培训、二次创作 |
| 质量门槛 | 无 | 无 | 字数 ±10%、章数 ≥8、中文占比 ≥70%、无占位符，脚本硬校验 |

## 工作原理

1. **解析源书为全文**：PDF 走 `pdftotext`，飞书/豆包文档走 `lark-cli docs +fetch`，全文落盘为 `full_text.txt`
2. **初始化工作目录**：`make_workspace.py` 生成四件套（checklist / outline / ledger / manuscript）
3. **规划**：定核心主张、章节结构、每章核心问题与目标字数，全书目标字数精确分配到章
4. **逐章成稿**：每章独立成稿，忠实转述，保留关键原句、角色与专有名词，去掉 AI 腔
5. **合并 + 校验**：合并 `final.md`，跑 `distill_check.py`，任何一项不达标不放行
6. **交付**：markdown + 原书 PDF；需要时上传云盘

## 校验门槛（写死在脚本里）

- 非空白字数 ∈ 目标 ±10%（默认目标 31,040 字，可调）
- 章节数 ≥ 8 且编号连续，章标题为 `# 第X章`
- 无占位符（TODO / 待补 / 占位 / xxx）
- 中文占比 ≥ 70%
- 每章非空白字符 ≥ 500
- 层级规范（"一、" → "（一）"），不跳级
- 章节目标字数合计 = 全书目标字数，台账已回填

## 常见问题

**Q：和直接让 AI 总结一本书有什么区别？**
A：总结是"提炼要点"，成书是"重建一本书"。成书有章节结构、论证线和完整表达，篇幅约 3 万字，可以直接交付给别人读；总结通常在几千字内，只能自己看。

**Q：会不会编造原书没有的内容？**
A：规则上禁止虚构。成书要求忠实转述原书，保留关键原句、案例与专有名词；无源书材料时直接停止，不生成。校验脚本会拦截占位符与空章节。

**Q：蒸馏出来的书能商用吗？**
A：不能直接商用分发。成书是原书内容的浓缩转述，版权归原作者与出版方。自用、内部培训、二次创作（在此基础上重写）需自行评估授权。

**Q：需要联网或付费 API 吗？**
A：不需要。脚本只用 Python 3 标准库；解析 PDF 需要本机有 `pdftotext`，处理飞书文档需要 `lark-cli`。

**Q：一次能蒸馏一份书单吗？**
A：能。按 `NN-书名` 自动编号，逐本产出，互不覆盖，适合几十本的批量作业。

**Q：支持英文书吗？**
A：支持英文源书，但成书输出为中文（中文占比 ≥70% 是硬门槛）。

**Q：可以只用它的校验脚本吗？**
A：可以。`scripts/distill_check.py` 可独立运行，传入任意成书目录即可检查字数、章节、占位符与中文占比。

## 边界（不做什么）

- 不做原创书籍创作（走 ai-novel-production）
- 不做 Word 排版与党政公文（走 word）
- 不做在线长文档协同创作（走 doubao-book-writer / lark-doc）
- 没有真实源书内容时不生成成书，不猜、不编

### 一客一码（卖出每一份都带唯一编号）

`scripts/issue_license.py` 为每个买家生成唯一授权编号、授权书与成书版权页，并记入本地台账；台账只存本地、不入库。

```bash
# 单个买家：生成授权书 + 版权页
python scripts/issue_license.py --buyer "张三" --order "订单号" --books all --output ./licenses

# 直接把版权页写进成书末尾，并嵌入隐蔽水印（可与编号互相印证）
python scripts/issue_license.py --buyer "张三" --books "01,46" \
    --embed deliverables/final.md --output ./licenses

# 拿到疑似盗版文件，反查它出自哪一份授权
python scripts/issue_license.py --decode 疑似盗版.md
```

编号形如 `FG-20261109-2TD8U5TY`，与台账一一对应。买到盗版文件后跑一次 `--decode`，就能读出它来自哪个买家的哪一份授权。
