# 平台投诉材料模板

本文提供闲鱼、淘宝、抖音、小红书、知识星球等平台的版权投诉正文模板。使用前先阅读 [权属证据整理方法](copyright-evidence.md) 与 [侵权对比清单](infringement-checklist.md)。

> 投诉是否受理、是否下架，由平台依据证据判断。本文不保证结果，也不构成法律意见。只陈述可核实的事实，不要虚构、夸大或披露买家隐私。

## 1. 投诉前准备

| 材料 | 是否必需 | 说明 |
|---|---|---|
| 权利人身份证明 | 通常必需 | 按平台要求提交，仅走平台渠道 |
| 作品权属证明 | 通常必需 | 仓库地址、首次提交、LICENSE、版本记录、软著证书等 |
| 侵权链接 | 必需 | 商品/内容完整 URL |
| 侵权对比材料 | 强烈建议 | 逐项对比表、截图、diff |
| 商业使用证据 | 强烈建议 | 价格、销量、付费课程/社群说明 |
| 授权边界说明 | 建议 | LICENSE、COMMERCIAL-LICENSE 截图 |
| 购买/交付证据 | 视情况 | 订单、交付文件、聊天记录 |
| 投诉人联系方式 | 必需 | 按平台要求填写，不要在公开正文泄露 |

## 2. 通用投诉正文模板

```text

1. 权属证明：{{仓库首次提交截图、LICENSE、NOTICE、版本记录、软著证书等}}
2. 侵权证据：{{商品页截图、录屏、价格/销量、购买订单、交付文件}}

2. 停止继续销售/传播

联系方式：{{按平台要求填写}}
```

## 3. 闲鱼投诉模板

闲鱼通常走“举报/知识产权投诉/盗版投诉”入口。正文建议简短、证据先行：

```text
投诉类型：知识产权侵权 / 盗版 / 未经授权销售

作品：Founder Guide（founder-guide）
原作：https://github.com/GodMaking/founder-guide-skill
首次公开：{{YYYY-MM-DD}}
权利人：{{姓名/主体}}

被投诉商品：{{商品链接}}
卖家：{{昵称}}
价格：{{金额}}
销量：{{数量，如可见}}

侵权事实：
1. 该商品未经授权，打包/复制/改名销售我的 Founder Guide Skill。
2. 我的许可证为 PolyForm Noncommercial License 1.0.0，仅允许个人非商业使用；商业销售需我的书面授权。
3. 对比证据：
   - {{文件目录/脚本/文档/案例/独特措辞的相同点}}
4. 该商品未保留 LICENSE / Required Notice / 授权编号（如属实）。

附件：
1. 仓库首次提交与版本记录截图
2. LICENSE 与 COMMERCIAL-LICENSE 截图
3. 商品页截图/录屏
4. 逐项对比表
5. 购买与交付证据（如有）

请求：下架商品、停止销售、保留记录。

声明：以上属实，愿承担虚假陈述责任；不披露买家隐私。

日期：{{YYYY-MM-DD}}
```

**注意**：

- 闲鱼可能要求“原创证明/权属证明”，提前准备仓库截图、软著证书、首发文章等
- 如果对方只是非商业分享，且保留 LICENSE 与署名，不建议按盗版投诉
- 不要在投诉正文公开买家姓名、电话、地址
- 保留投诉编号与平台回复截图

## 5. 抖音/小红书/视频号投诉模板

适用于对方用短视频、图文、直播切片销售或引流：

```text
投诉类型：著作权侵权 / 盗版课程 / 未经授权销售

作品：Founder Guide（founder-guide）
原作：https://github.com/GodMaking/founder-guide-skill
权利人：{{姓名/主体}}

被投诉内容：
- 账号：{{昵称/ID}}
- 视频/图文/直播链接：{{URL}}
- 发布时间：{{YYYY-MM-DD}}
- 侵权形式：{{售卖资料包/付费课程/引流私域/改名后销售}}

侵权说明：
1. 内容中展示/销售/交付的文件与我享有著作权的 Founder Guide 高度相似。
2. 对比证据：{{逐项对比}}
3. 我的许可证仅允许个人非商业使用，对方未取得商业授权。

请求：下架内容、停止传播、限制相关商品/课程。

声明：信息真实，愿承担虚假陈述责任；不披露买家隐私。
日期：{{YYYY-MM-DD}}
```

**注意**：

- 录屏要包含账号主页、视频内容、商品/引流入口、发布时间
- 如果对方只是“提到”或“评价”你的作品，属于合理使用/评论，不要误投诉
- 如果对方售卖的是自己的独立课程，只是主题相似，不要按复制投诉

## 7. 发给卖家的通知模板（可选）

如果对方是偶发、非恶意、愿意沟通的卖家，可以先发一条事实清楚的通知，不一定直接投诉：

```text
你好，我是 Founder Guide（https://github.com/GodMaking/founder-guide-skill）的作者。

你正在销售的 {{商品/资料}} 包含我的作品。我的许可证是 PolyForm Noncommercial License 1.0.0，仅允许个人非商业使用；商业销售需要我的书面授权。

请你在 {{X}} 天内：
1. 下架相关商品/内容；
2. 停止继续销售或传播；
3. 如你希望继续商业使用，请联系我申请授权。

如已下架，请回复我链接，我不会继续追究。谢谢。
```

**不要**威胁、辱骂、曝光个人信息或诱导对方转账。

## 8. 平台驳回/对方申诉时怎么办

1. 查看平台驳回理由，确认缺的是权属证明、对比材料还是授权说明
2. 补充材料，不要重复提交同一份内容
3. 如果对方主张独立开发，要求其提供创作记录，并补充你的时间线与对比证据
4. 如果平台要求软著证书，考虑申请软件著作权登记
5. 如果涉及较大金额、反复侵权或跨平台销售，咨询律师
6. 全程保存投诉编号、回复截图、时间线

## 9. 投诉材料检查清单

- [ ] 作品名称、仓库地址、首次公开时间准确
- [ ] 权属证明齐全
- [ ] 侵权链接、卖家、价格、销量、发布时间齐全
- [ ] 对比材料逐项、具体、可核验
- [ ] 明确说明许可证与商业授权边界
- [ ] 排除非商业许可允许的使用
- [ ] 考虑独立开发可能
- [ ] 没有披露买家隐私
- [ ] 没有虚构、夸大、恶意陈述
- [ ] 保存了投诉编号与平台回复

## 10. 边界

- 平台是否受理、是否下架，由平台依据证据判断
- 投诉不保证成功，也不等于法院判决
- 公开源码不能从技术上阻止复制
- 独立开发类似功能不一定侵权
- 著作权保护表达，不保护思想、方法、概念
- 恶意投诉、虚假投诉可能承担法律责任
- 本文不构成法律意见
